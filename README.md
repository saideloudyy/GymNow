# GymNow

A premium, mobile-first gym and fitness tracker designed for GitHub Pages.

## Included
- Premium responsive dashboard
- Dark / light mode
- Weight tracker with KG / LB
- Weight goal and progress percentage
- Weight history and visual chart
- Workout templates with zones and exercises
- Weekly gym plan
- Workout/rest timer
- Calorie needs calculator (Mifflin-St Jeor estimate)
- Calories gained / food log
- Calories burned / activity log
- LocalStorage persistence (data stays in the browser)
- Mobile-friendly navigation

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a new GitHub repository, e.g. `gymnow`.
2. Upload `index.html`, `style.css`, and `app.js`.
3. Go to Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Choose the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

The background image is loaded from the image URL specified for the GymNow design.
